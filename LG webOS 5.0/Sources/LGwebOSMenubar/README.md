# Source notes

This folder holds the Swift code for the menu bar app. It targets **LG webOS TVs**. Testing so far covers webOS 5.0 on one LG TV, as described in the repository README.

Other models and webOS versions may use different permissions, endpoints, or behavior. Please say which TV model and webOS version you tested when you open a pull request that changes how the app talks to the TV.

`registration.json` is the public LG test-client manifest from PyWebOSTV. See `THIRD_PARTY_NOTICES.md` in the repository root.
