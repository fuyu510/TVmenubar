# TVmenubar-MacOS setup guide

This repository contains two independent native macOS menu bar apps. First identify the TV operating system, then work only in the matching folder:

- `LG webOS 5.0/` for LG webOS. Follow its `CLAUDE.md` for build, pairing, and checks.
- `Roku OS 15.3.4/` for Roku OS. Follow its `README.md` for build and TV configuration.

The folder versions are verified versions, not an instruction to reject other versions. Check compatibility before promising that an untested TV will work.

Never place a user's IP address, MAC address, serial number, TV model, pairing key, or diagnostic output in tracked files. Keep local values in app settings or ignored `.local/` directories. Ask before sending commands that change the TV's state. Do not commit or push changes unless the user authorizes it.
